# AssetVal Pro
Company Asset Valuation • Inventory • Audit • Depreciation

The MVP is available in **index.html** and runs directly in a modern browser.

Workflow:
Create Company → Add Locations → Add/Import Assets → Verify Assets → Calculate Depreciation → Review Valuation → Generate Report

Included:
- Company setup and base currency
- Locations
- Asset register
- CSV import/export
- Verification and audit
- Straight-line depreciation
- Book/market value review
- Print/PDF report
- Responsive desktop/mobile layout
